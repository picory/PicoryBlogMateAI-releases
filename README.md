# 블로그메이트 설치 파일

블로그 글을 AI로 만들고 네이버 블로그에 올리는 데스크톱 앱 **블로그메이트**의 설치 파일을 배포하는 곳입니다.
소스 코드는 여기에 없습니다.

## 내려받기

[최신 릴리스](https://github.com/picory/PicoryBlogMateAI-releases/releases/latest)에서 내 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 파일 |
|---|---|
| 맥(Apple 실리콘·Intel 모두) | `PicoryBlogMate_버전_darwin_universal.dmg` |
| 윈도우 10/11 (64비트) | `PicoryBlogMate_버전_windows_x86_64-setup.exe` |

한 번 설치하면 새 버전이 나왔을 때 앱 아래줄에 **[새 버전 업데이트]** 버튼이 나타나고, 누르면 알아서 받아 설치합니다.

## 처음 설치할 때 경고가 떠요

아직 코드 서명 인증서가 없어서 운영체제가 경고를 보여 줍니다.

- **맥**: "확인되지 않은 개발자" → Finder에서 앱을 **오른쪽 클릭 → 열기** → 다시 **열기**. (그래도 열리지 않으면 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기")
- **윈도우**: "Windows의 PC 보호" → **추가 정보** → **실행**.

## 문의

앱 아래줄의 벌레 아이콘(진단 로그)에서 기록을 복사해 보내 주세요.
