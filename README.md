# 블로그메이트 (PicoryBlogMate)

블로그 글을 AI로 만들고 **네이버·티스토리·블로그스팟·워드프레스**에 올리는 데스크톱 앱입니다(macOS·Windows).
이 저장소는 **설치 파일만** 배포하는 곳입니다. 소스 코드는 여기에 없습니다.

---

## 내려받기

[**최신 릴리스**](https://github.com/picory/PicoryBlogMateAI-releases/releases/latest)에서 내 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 파일 |
|---|---|
| 맥 (Apple 실리콘·Intel 모두) | `PicoryBlogMate_<버전>_darwin_universal.dmg` |
| 윈도우 10/11 (64비트) | `PicoryBlogMate_<버전>_windows_x64-setup.exe` |

한 번 설치하면, 새 버전이 나왔을 때 앱 아래줄에 **[새 버전 업데이트]** 버튼이 떠서 누르면 알아서 받아 설치합니다.

### 설치할 때 경고가 떠요 (정상입니다)

아직 코드 서명 인증서가 없어 운영체제가 경고를 보여 줍니다.

- **맥**: "확인되지 않은 개발자" → Finder에서 앱을 **오른쪽 클릭 → 열기** → 다시 **열기**. (그래도 안 열리면 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기")
- **윈도우**: "Windows의 PC 보호(SmartScreen)" → **추가 정보** → **실행**.

## 상품·가격

처음에는 **7일 무료 체험**으로 써 볼 수 있습니다.

| 상품 | 가격 | 계정 수 | 하루 글 등록 | 비고 |
|---|---|---|---|---|
| **7일 체험** | 무료 | 1개 | 5개/일 | 이메일 등록 시 시작 |
| **월 구독** | 10만원 / 월 | 제한 없음 | 제한 없음 | |
| **연 구독** | 100만원 / 년 | 제한 없음 | 제한 없음 | 월 구독 대비 2개월 혜택 |
| **평생회원 (1copy)** | 150만원 (1회) | 5개 | 제한 없음 | 한 번 결제, 영구 사용 |
| **평생 무제한** | 200만원 (1회) | 무제한 | 제한 없음 | 한 번 결제, 영구 사용 |

### 공통 원칙
- **1 PC · 1 COPY** — 모든 상품은 한 대의 컴퓨터에서만 씁니다. 하나의 시리얼 키는 한 기기에 묶입니다.
- **재설치·기기 변경 시 확인 요청** — 컴퓨터를 바꾸거나 재설치하면 자동으로 풀리지 않습니다. 관리자에게 해제를 요청해야 새 기기에서 다시 활성화됩니다.
- 체험판은 **1개 계정 · 하루 5개 글**로 제한됩니다. 유료 상품에서 풀립니다.

## 앱 인증 방법

### 1. 체험(7일)
1. 앱을 설치하고 처음 켜면 설치 마법사가 열립니다.
2. **이메일을 등록**하면 7일 체험이 시작됩니다.
3. 체험 동안은 블로그 계정 1개, 하루 5개 글까지 올릴 수 있습니다.

### 2. 유료(시리얼 키)
1. 상품을 구매하면 **시리얼 키**를 받습니다.
2. 앱의 설치 마법사(시리얼 키 칸)에 키를 넣습니다.
3. 키는 이 컴퓨터에 암호화되어 저장되고, **앱을 켤 때마다 서버로 다시 확인**합니다.
4. 처음 확인한 순간 **키가 그 기기에 묶입니다**(1 PC · 1 COPY). 다른 컴퓨터에서 같은 키를 쓰면 "다른 시스템에서 이미 활성화된 시리얼 키입니다."로 막힙니다.

### 3. 재설치·기기 변경
- 같은 컴퓨터에 다시 설치할 때도 **확인(재활성) 요청**이 필요할 수 있습니다.
- 컴퓨터를 바꿀 때는 이전 기기의 활성화를 **해제**한 뒤 새 기기에서 다시 등록합니다. 해제는 관리자 확인으로만 됩니다.
- 해제·재활성 요청은 아래 [문의](#문의)로 보내 주세요.

> 비밀번호를 앱에 저장하거나 자동으로 입력하지 않습니다. 각 블로그 로그인은 로그인 창에서 직접 하고, 로그인은 계정마다 따로 유지됩니다.
